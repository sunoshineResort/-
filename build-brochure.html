Build the brochure PDF

This page rebuilds the brochure from the photo sections in index.html. Run it after adding or removing photos, then save the download over brochure/Sun-Shine-Resort-Brochure.pdf so the website's Brochure PDF button serves the new version.

It must be opened over http — a local server or the live site. Opened from a file:// path, browsers block reading the photos and the build fails.
